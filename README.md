# Inventory Management System – Client

      The web front end for managing IT department assets, tracking devices and
      accessories and their assignments.
      
      Connects to the [InventoryManagementSystem](https://github.com/osamakhader-3000/InventoryManagementSystem) API.

## Tech Stack
      - React
      - TypeScript
      - Vite

## Getting Started
      1. Install Node.js.
      2. Install dependencies: `npm install`
      3. Set the API URL in your `.env` file.
      4. Start the dev server: `npm run dev`
